# MEMTRACE dashboard

The React app for MEMTRACE's Executive View (savings, cost avoided, memory story) and Engineering View (retrieval detail, LangSmith trace IDs).

See the [project README](../README.md) for how to build and run this alongside the backend.

```bash
npm install
npm run dev      # hot-reload dev server at http://localhost:5173, proxies API calls to the backend on :8000
npm run build    # production build, served by the FastAPI backend from dist/
```
